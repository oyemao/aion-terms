# Aion永恒之塔频道翻译器 - 在线术语字典

本仓库用于维护 [Aion永恒之塔频道翻译器](https://github.com/oyemao/aion-terms) 的在线术语字典，所有用户共享同一份术语库，翻译质量越用越好。

## 仓库说明

- `term.json` - 主术语字典，程序启动时自动从本仓库拉取
- 术语格式：`{"原词": "中文释义"}`
- 在线术语优先于本地术语，相同词条以在线版本为准

## 如何贡献新术语

### 方式一：提交Issue（推荐新手）

1. 点击上方 `Issues` 标签
2. 点击 `New issue`
3. 标题格式：`[术语] 原词 = 中文释义`
   - 示例：`[术语] ДРАБА = 龙洞`
4. 提交后等待管理员审核合并

### 方式二：提交Pull Request（适合会用Git的用户）

1. Fork本仓库到你的账号
2. 修改 `term.json`，添加新术语
3. 提交Pull Request
4. 等待管理员审核合并

## 术语规范

### 翻译原则
- 优先使用Aion国服/台服通用译名
- 游戏黑话/缩写尽量翻译为国内玩家习惯的说法
- 副本名、BOSS名、装备名保持一致性
- 不确定的词可以标注 `(待确认)` 或先保留原文

### 格式要求
```json
{
  "ДРАБА": "龙洞",
  "УДАС": "乌达斯神殿",
  "WTS": "出售",
  "WTB": "求购"
}
```

### 常见术语分类
- **副本名**：ДРАБА(龙洞)、УДАС(乌达斯)、ТЕО(天本)
- **职业名**：СОРК(魔道星)、СИН(杀星)、ГЛАД(剑星)
- **游戏缩写**：WTS(出售)、WTB(求购)
- **装备/道具**：ГИР(装备)、МЕДАЛИ(勋章)、АМУЛЬ(符咒)
- **动作/状态**：КАЧ(练级)、ФАРМ(刷怪)、БП(背包)

## 本地新增术语

程序运行时会自动将未识别的疑似术语保存到本地 `new_terms.json` 文件，你可以：

1. 打开程序目录下的 `new_terms.json`
2. 整理确认翻译准确的术语
3. 通过Issue或PR提交到本仓库
4. 管理员审核后合并，所有人自动同步

## 注意事项

- 请勿提交敏感信息、广告、违法内容
- 请勿恶意修改已有术语的正确翻译
- 重复术语会被自动忽略
- 术语字典会在程序启动时自动拉取最新版本，无需手动更新
